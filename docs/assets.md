# 素材リスト v0.1

見た目を強化するために必要な素材の一覧。用意できたものから順に `public/assets/` の下に置けば、ゲームに組み込む。
いまの絵文字・色だけの表示は仮のもの。

- 優先度 **A**: これがあると見た目が大きく変わる。最初に用意したい
- 優先度 **B**: あると良い。Aの後で
- 優先度 **C**: 余裕があれば。なくてもCSSや既存の表示で代わりがきく

---

## 共通のルール

| 項目 | 決まり |
|---|---|
| 画像の形式 | **PNG（背景は透過）**。写真のような大きい絵は WebP でも可 |
| 画像の大きさ | 下の表の「サイズ」以上。スマホの高画質画面（3倍）でもぼやけないよう、表示サイズの約3倍にしている |
| 音の形式 | **MP3**（iPhone・Androidの両方で鳴る） |
| ファイル名 | 下の表の「ファイル名」のとおり（半角英数字）。違う名前でも、対応表をもらえれば合わせる |
| 絵柄 | 仕様どおり **かわいいちびキャラのファンタジー**。全素材で絵柄・線の太さ・色の明るさをそろえる |
| ライセンス | フリー素材・生成素材を使う場合は、**配布元・利用規約・クレジット表記の要否** を `public/assets/CREDITS.md` に書く（GitHub Pagesで公開するため、Web公開と改変が許されているものに限る） |

## 1. キャラクター（コマ）　優先度 A

4人分。ボード上のコマ・プレイヤー一覧・カード使用時の表示に使う。いまは 🧙‍♀️🧙🧝🧚 の絵文字。

| ファイル名 | 内容 | サイズ | 備考 |
|---|---|---|---|
| `chara/p1.png` | 1人目（ピンク系） | 256×256 | 全身のちびキャラ、正面〜やや斜め |
| `chara/p2.png` | 2人目（青系） | 256×256 | |
| `chara/p3.png` | 3人目（黄色系） | 256×256 | |
| `chara/p4.png` | 4人目（緑系） | 256×256 | |

- 各プレイヤーの色はいまの色（ピンク `#e8577a`・青 `#4a90e2`・黄 `#f2b632`・緑 `#5cb85c`）に合わせると、ボード上で見分けやすい。
- ボード上では直径30px程度と小さく表示されるので、**シルエットと色だけで見分けられる** デザインが良い。
- キャラは魔法使いまたは魔法剣士。顔は目のみを描く（鼻・口はなし）
- 優先度 B: 表情差分。下の「1.1 バストアップ」を参照。

### 1.1 バストアップ（メッセージ窓の上の手番キャラ）　優先度 B

いまは全身の絵（`chara/p1.png`）から頭〜胸を切り抜いて表示している。専用の絵を置くと、そちらを使う。
表情の絵が無いときは、ふつうの顔（`chara/bust/p1.png`）→ 全身の絵の切り抜き、の順に代わりを使うので、そろった表情から少しずつ置いてよい。

| ファイル名 | 表情 | 出る場面 |
|---|---|---|
| `chara/bust/p1.png` | ふつう | 下のどれにも当てはまらないとき |
| `chara/bust/p1_happy.png` | 笑顔 | 1位のとき（単独トップ） |
| `chara/bust/p1_frown.png` | しかめっ面 | 最下位のとき |
| `chara/bust/p1_brave.png` | 勇ましい顔 | 自分の手番中にカードを使った・攻撃を防いだ |
| `chara/bust/p1_sad.png` | 悲しい顔 | 自分の手番中に攻撃を受けた・押し戻された |

- p2〜p4 も同じ名前で用意する（`chara/bust/p2_happy.png` など）。
- サイズは 256×256（1:1）、背景は透過。枠いっぱいに、頭が上のほうに来るように描く。
- カードを使った・攻撃を受けたときの顔は、その手番が終わるまで続く。表情の種類を増やすときは `src/ui/expression.ts` に足す。

## 8. 効果音（SE）　優先度 B

短い音（1秒前後）。

| ファイル名 | 鳴るとき |
|---|---|
| `se/dice.mp3` | サイコロを振る |
| `se/step.mp3` | コマが1マス進む（何度も鳴るので、ごく短く軽い音）。いまの素材は足音が約10秒続くので、ゲームでは最初の0.3秒だけを鳴らしている |
| `se/card.mp3` | カードを使う |
| `se/attack.mp3` | 攻撃を受ける（戻される・休み・奪われる） |
| `se/guard.mp3` | 光の壁で防ぐ／反射の鏡ではね返す |
| `se/trap.mp3` | 罠を踏む |
| `se/draw.mp3` | カードを引く |
| `se/coin.mp3` | コインを取る |
| `se/gate_fail.mp3` | 関所で失敗（封印にひびが入る） |
| `se/gate_pass.mp3` | 関所を通過する／封印が砕ける |
| `se/turn.mp3` | 自分のターンが来た |
| `se/goal.mp3` | ゴール（ファンファーレ） |
| `se/click.mp3` | ボタンを押す（優先度 C） |

- 組み込み済み。鳴らす場面と音量・切り取りは `src/ui/sound.ts` で変えられる。
- 音のオン・オフは、タイトル画面とゲーム画面の右上のボタンで切り替える（最初はオフ。端末ごとに覚える）。

## 9. BGM　優先度 C

ループ再生する。ループの継ぎ目が自然につながるもの。

| ファイル名 | 流れるとき |
|---|---|
| `bgm/title.mp3` | タイトル画面 |
| `bgm/forest.mp3` | はじまりの森でのゲーム中 |
| `bgm/result.mp3` | 結果発表 |

- 音を出す前に、画面のどこかに **音のオン／オフ切り替え** を付ける（スマホでいきなり鳴らないように、最初はオフ）。
