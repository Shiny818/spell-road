## 世界観と絵柄

- **デフォルメされたファンタジー魔法世界**。見習い魔法使いたちが、魔法のカードを使って森や塔をすごろくで進む。
- **温かみのある絵柄**。絵本のようなやわらかさ。こわい・暗い・リアルな表現は避ける（闇属性も「いたずらっぽい」程度にとどめる）。
- キャラクターは 2〜2.5頭身のちびキャラ。**顔は目だけ**（鼻・口は描かない）。

## 共通スタイル（全カテゴリ共通）

各カテゴリのファイルの「① 最初に送るプロンプト」には、下の文章がそのまま入っている。
**絵柄を変えるときは、ここと全ファイルの①を同じように書き換える。**

```
【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない
```

## Gemini での作り方

### 基本の流れ
1. カテゴリごとに **新しいチャット** を開く（別カテゴリの指示が混ざらないように）。
2. そのカテゴリの「① 最初に送るプロンプト」を送る。共通スタイルとカテゴリのルールを覚えさせる。
3. 「② 素材ごとのプロンプト」を1つずつ送る。気に入るまで「もう一度」「〇〇をもっと△△に」と直してもらう。
4. 1枚目で絵柄が決まったら、その画像を **参考画像として添付** し、「この画像と同じ絵柄・線・色の明るさで」と付け加えて残りを作る。
5. 途中で絵柄がずれてきたら、①をもう一度送り直す（またはチャットを作り直す）。

### 絵柄をそろえるコツ
- **最初に「基準の1枚」を決める**。おすすめは `chara/p1.png`。決まったら、他のカテゴリでも最初にこの画像を添付して「この絵柄に合わせて」と伝える。
- 同じグループの素材（サイコロ6枚、属性アイコン6枚など）は、**1枚目を作ってから「この画像を元に、〇〇だけ変えて」と編集してもらう** と形がそろう。
- 一度にたくさん頼まず、1回に1枚ずつ作る。

### 背景の透過について
Gemini は **透過PNGを直接出せない**。そのため、背景を無地の単色で作ってもらい、あとで背景を消す。

| 素材の色 | 背景の指定 |
|---|---|
| ふつう | 「背景は無地の真っ白一色」 |
| 白・水色・金色が多い素材（氷・光・霜など） | 「背景は無地の濃いマゼンタ（#FF00FF）一色」 |

- 背景を消す道具: remove.bg、Adobe Express の背景削除、GIMP・Photoshop など。
- 地面の影・床の反射が入ると消しにくいので、プロンプトでも「影や地面は描かない」と伝えている。
- 消したあと、輪郭に白やマゼンタのふちが残っていないか、**暗い背景の上に置いて** 確かめる。

### 縦横比とサイズ
- Gemini で作れる大きさは素材リストのサイズより大きいので、**作ったあとで縮小** する（拡大はしない）。
- 縦横比はプロンプトの最後に「縦横比は〇:〇」と書いている。違う比率で出てきた場合は、もう一度指定するか、切り抜いて合わせる。

| 素材リストのサイズ | 縦横比 | 後処理 |
|---|---|---|
| 256×256、192×192、128×128、96×96 | 1:1 | 縮小 |
| 480×360 | 4:3 | 縮小 |
| 240×320 | 3:4 | 縮小 |
| 512×512（つなぎ目なし） | 1:1 | 縮小＋つなぎ目の確認（[06_bg.md](06_bg.md)） |
| 1080×1920 | 9:16 | 縮小 |
| 1200×480 | 5:2 | 16:9 などで作って上下を切る |

### 透かしについて
- Gemini で作った画像には、目に見えない電子透かし（SynthID）が入る。これは見た目に影響しない。
- プランによっては **画像の隅に目に見えるマーク** が入ることがある。入っていたら、使う前に切り抜くか消す（消してよいかは、その時点の Gemini の利用規約で確かめる）。

## 仕上げのチェックリスト

- [ ] ファイル名は素材リストのとおり（半角英数字）
- [ ] 背景が透過されている（カード・背景画像は除く）
- [ ] 素材リストのサイズに縮小した
- [ ] 小さく表示しても何の絵かわかる（スマホで実際の表示サイズにして見る）
- [ ] ほかの素材と並べて、絵柄・線の太さ・色の明るさがそろっている
- [ ] 文字・透かしが入っていない
- [ ] `public/assets/` の下に置いた

## 記録（CREDITS.md）

生成素材を使うときは、`public/assets/CREDITS.md` に次のように書く。

```
## 画像生成AIで作った素材
- 生成サービス: Google Gemini（モデル名: 〇〇）
- 生成日: 2026-xx-xx
- 対象: public/assets/chara/、card/、…
- 利用規約: （確認した規約のURL）を確認し、Web公開・改変が許されていることを確認した
- 使ったプロンプト: docs/assets-prompts/ を参照
```

プロンプトを直して良い結果が出たら、このフォルダのファイルも直しておく（次に作り直すときのため）。
