# 3. 罠・状態のアイコンのプロンプト

| 項目 | 内容 |
|---|---|
| 対象 | `icon/trap_fire.png`・`trap_ice.png`（128×128）、`icon/status_rest.png`・`status_frost.png`・`crack.png`（96×96）。すべて優先度 B |
| 縦横比 | 1:1 で作って縮小 |
| 背景 | 透過。**氷・霜の素材は白っぽいので、マゼンタ一色で作ってあとで消す** |
| 基準 | [02_square.md](02_square.md) のマスのアイコンを添付すると、線の太さがそろう |

## デザインの考え方

- **罠**（trap_）はマスの上に重ねて置く。真上〜やや上から見た、平たい魔法陣にする。
- **状態**（status_）はキャラクターの横に小さく出すバッジ。96px で表示されるので、とくに単純な形にする。
- 「-2」などの **数字は描かない**（必要ならプログラムで重ねる）。

---

## ① 最初に送るプロンプト

```
これから、すごろくゲームの「罠」と「状態」を表す小さなアイコンを1つずつ描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【アイコンのルール】
・ゲームの小さなアイコン。物を1つだけ、画面の中央に大きく描く（画面の約8割の大きさ）
・とても小さく表示しても何かわかるように、形をはっきり・単純にする。細かい模様は少なめ
・主線はほかのイラストより少し太めにする
・人物は描かない
・こわくなりすぎず、コミカルでかわいい雰囲気にする
・背景は指定した色の無地一色。地面・影・背景の飾りは描かない
・縦横比は1:1

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `icon/trap_fire.png`（炎の魔法陣の罠）
```
「炎の魔法陣の罠」のアイコンを描いてください。マスの上に置く罠です。
・やや上から見下ろした、平たい円形の魔法陣。赤とオレンジで光っている
・魔法陣の模様は、二重の円と、炎の形の簡単な記号（文字は入れない）
・魔法陣のふちから、小さな炎がちろちろと3〜4本立ちのぼっている
・背景は無地の真っ白一色
```

### `icon/trap_ice.png`（凍てつく床の罠）
```
「凍てつく床の罠」のアイコンを描いてください。マスの上に置く罠です。
・やや上から見下ろした、平たい円形の氷の床。水色で、表面がつるつる光っている
・氷の上に、雪の結晶の形の簡単な魔法陣の模様（文字は入れない）
・ふちから小さなつららや氷のとげが少し立ち上がっている
・氷の線や影は、白ではなく濃い水色や青で描く
・背景は無地の濃いマゼンタ（#FF00FF）一色
```

### `icon/status_rest.png`（1回休み・凍りついた）
```
「1回休み（凍りついて動けない）」の状態を表すアイコンを描いてください。
・四角くてまるっこい、水色の氷のかたまりを1つ
・氷のかたまりの上に、白い「Z」の形を大きさ違いで3つ（眠っているマーク。これだけは記号として描いてよい）
・氷の線や影は、白ではなく濃い水色や青で描く
・背景は無地の濃いマゼンタ（#FF00FF）一色
```

### `icon/status_frost.png`（霜の呪い・次の出目-2）
```
「霜の呪い（次のサイコロの目が小さくなる）」の状態を表すアイコンを描いてください。
・水色の雪の結晶を1つ、中央に大きく
・結晶のまわりを、うすい紫色のもやもやしたオーラが包んでいる（呪いを表す）
・結晶の右下に、下向きの小さな矢印（紫色）
・数字は描かない
・背景は無地の濃いマゼンタ（#FF00FF）一色
```

### `icon/crack.png`（関所のひび）
```
「封印にひびが入った」ことを表すアイコンを描いてください。
・青紫色に光る丸い魔法の封印（魔法陣の紋章）を正面から
・封印に、ギザギザの白く光るひびが1本、上から斜めに入っている
・ひびのまわりに、小さなかけらが2つ飛んでいる
・背景は無地の真っ白一色
```

> `crack.png` は、ボードの関所（[02_square.md](02_square.md) の `gate.png`）の封印と同じ見た目にしたいので、`gate.png` を添付して「この扉の封印と同じ色・模様で」と付け加えるとよい。

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| 氷が背景と同化する | 「背景を無地の濃いマゼンタ（#FF00FF）にしてください」 |
| 魔法陣に文字が入る | 「魔法陣の中の文字をすべて消して、円と簡単な図形だけにしてください」 |
| こわい雰囲気になる | 「もっとまるっこく、かわいい雰囲気にしてください」 |
