# 5. 属性アイコンのプロンプト

| 項目 | 内容 |
|---|---|
| 対象 | `attr/wind.png`・`time.png`・`fire.png`・`ice.png`・`light.png`・`dark.png`（すべて優先度 B） |
| サイズ | 96×96（縦横比 1:1 で作って縮小） |
| 背景 | 透過。**氷・光は白っぽいので、マゼンタ一色で作ってあとで消す** |

## デザインの考え方

- カードの左上に小さく表示する。**6つとも同じ形のメダル** にして、中のシンボルと色だけを変える。
- 形をそろえるため、**最初に `wind.png` を作り、残りの5つは `wind.png` を添付して編集してもらう**。

| ファイル | 属性 | 色 | シンボル |
|---|---|---|---|
| `wind.png` | 風 | 緑 | うずを巻く風と木の葉1枚 |
| `time.png` | 時 | 紫 | 砂時計 |
| `fire.png` | 炎 | 赤 | しずく形の炎 |
| `ice.png` | 氷 | 水色 | 雪の結晶 |
| `light.png` | 光 | 金 | 光を放つ太陽 |
| `dark.png` | 闇 | 黒紫 | 三日月 |

---

## ① 最初に送るプロンプト

```
これから、ゲームの魔法カードの「属性」を表す小さなアイコンを6つ描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【属性アイコンのルール】
・正面から見た、円形のメダル。メダルの外枠は細い金色の縁
・メダルの中は属性の色で塗り、中央にその属性のシンボルを白またはクリーム色で大きく描く
・とても小さく表示するので、シンボルは単純な形にする
・メダルは画面いっぱい（上下左右に少しだけ余白）
・6つとも、メダルの形・大きさ・縁の太さ・シンボルの大きさをそろえる
・背景は指定した色の無地一色。影は描かない
・縦横比は1:1

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `attr/wind.png`（風）— 最初に作る
```
「風」属性のアイコンを描いてください。
・メダルの中は明るい緑色
・シンボルは、うずを巻く風の線と、木の葉1枚（クリーム色）
・背景は無地の真っ白一色
```

### 残りの5つ
`wind.png` を添付して、次のプロンプトを1つずつ送る。

#### `attr/time.png`（時）
```
添付したアイコンと、メダルの形・大きさ・縁・絵柄をまったく同じにして、中身だけ変えてください。
・メダルの中は紫色
・シンボルは砂時計（クリーム色）
・背景は無地の真っ白一色、縦横比は1:1
```

#### `attr/fire.png`（炎）
```
添付したアイコンと、メダルの形・大きさ・縁・絵柄をまったく同じにして、中身だけ変えてください。
・メダルの中は赤色
・シンボルは、しずくの形をした炎（クリーム色、炎の芯は黄色）
・背景は無地の真っ白一色、縦横比は1:1
```

#### `attr/ice.png`（氷）
```
添付したアイコンと、メダルの形・大きさ・縁・絵柄をまったく同じにして、中身だけ変えてください。
・メダルの中は水色
・シンボルは雪の結晶（白）
・背景は無地の濃いマゼンタ（#FF00FF）一色、縦横比は1:1
```

#### `attr/light.png`（光）
```
添付したアイコンと、メダルの形・大きさ・縁・絵柄をまったく同じにして、中身だけ変えてください。
・メダルの中は明るい金色（縁の金色より少しオレンジ寄りにして、縁と見分けられるようにする）
・シンボルは、まわりに光の線を放つ丸い太陽（白）
・背景は無地の濃いマゼンタ（#FF00FF）一色、縦横比は1:1
```

#### `attr/dark.png`（闇）
```
添付したアイコンと、メダルの形・大きさ・縁・絵柄をまったく同じにして、中身だけ変えてください。
・メダルの中は黒に近い濃い紫色
・シンボルは三日月と、小さな星1つ（クリーム色）
・背景は無地の真っ白一色、縦横比は1:1
```

---

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| メダルの形がそろわない | 「添付した画像のメダルの外枠をそのまま使って、中の色とシンボルだけ差し替えてください」 |
| シンボルが細かすぎる | 「シンボルをもっと太く単純にしてください。とても小さく表示します」 |
