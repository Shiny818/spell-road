# 1. キャラクター（コマ）のプロンプト

| 項目 | 内容 |
|---|---|
| 対象 | `chara/p1.png`〜`chara/p4.png`（優先度 A）、表情差分 `p1_happy.png` など（優先度 B） |
| サイズ | 256×256（縦横比 1:1 で作って縮小） |
| 背景 | 透過（白一色で作って、あとで消す） |
| 基準 | **`p1.png` を全素材の絵柄の基準にする**。最初に作って、絵柄を決める |

## デザインの考え方

- ボード上では **直径30px程度** と小さい。**シルエット（帽子・武器・マントの形）とメインカラー** だけで4人を見分けられるようにする。
- 4人とも同じ頭身・同じ線・同じ塗りにする。違うのは「色」と「シルエット」。
- 顔は **目だけ**。鼻と口は描かない。

| ファイル | メインカラー | 職業 | シルエットの決め手 |
|---|---|---|---|
| `p1.png` | ピンク `#e8577a` | 見習い魔女 | つばの広い、先がくにゃりと曲がったとんがり帽子＋ハート形の飾りの杖 |
| `p2.png` | 青 `#4a90e2` | 見習い魔法使い | 細くて背の高い、まっすぐなとんがり帽子（星の飾り）＋長いローブ＋背より高い杖 |
| `p3.png` | 黄 `#f2b632` | 魔法剣士 | 帽子なし、はねた髪とヘアバンド＋短いマント＋光る剣を掲げる |
| `p4.png` | 緑 `#5cb85c` | エルフの魔法使い | 葉っぱの形のフード（とがった耳が出る）＋羽のような形のマント＋小さな花のついた杖 |

## ① 最初に送るプロンプト

```
これから、すごろくゲームのプレイヤーのコマに使うキャラクターを1人ずつ描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【キャラクターのルール】
・2〜2.5頭身のちびキャラ。頭が大きく、手足は短くて丸い
・顔は目だけを描く。目は大きめの縦長の楕円で、白いハイライトを1つ入れる。鼻と口は絶対に描かない。ほっぺに薄い赤みを入れる
・全身を、正面からやや斜め（向かって左を少し向く）の角度で描く。足元まで画面に入れる
・キャラクター1人だけを画面の中央に置き、上下左右に少し余白をとる
・とても小さく表示しても、シルエットと色だけで誰かわかるように、帽子や武器の形をはっきりさせる
・服の色はメインカラー1色を中心にし、差し色は白・クリーム色・こげ茶色だけにする
・背景は無地の真っ白一色。地面・影・エフェクト・小物の背景は描かない
・縦横比は1:1

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `chara/p1.png`（ピンク・見習い魔女）
```
1人目のキャラクターを描いてください。
・見習いの魔女の女の子。メインカラーはピンク（#e8577a）
・つばの広い、先がくにゃりと後ろに曲がったピンクのとんがり帽子。帽子に白いリボン
・ふんわりしたピンクのケープとワンピース、白い襟、こげ茶色の小さなブーツ
・クリーム色の髪を肩の長さで、ゆるく内巻き
・右手に、先にハート形の飾りがついた短い杖を持ち、元気に掲げている
・目だけの顔（鼻と口なし）で、明るく楽しそうな雰囲気
```

### `chara/p2.png`（青・見習い魔法使い）
```
2人目のキャラクターを描いてください。1人目と同じ絵柄・頭身・線の太さ・色の明るさにしてください。
・見習いの魔法使いの男の子。メインカラーは青（#4a90e2）
・細くて背の高い、まっすぐ上にのびた青いとんがり帽子。帽子に金色の星の飾り
・足首まである青いローブ、白い縁取り、こげ茶色のベルト
・こげ茶色の短い髪が帽子の下から少し見える
・自分の背より高い、先に丸い水晶がついた木の杖を両手で持っている
・目だけの顔（鼻と口なし）で、まじめで落ち着いた雰囲気
```

### `chara/p3.png`（黄・魔法剣士）
```
3人目のキャラクターを描いてください。1人目と同じ絵柄・頭身・線の太さ・色の明るさにしてください。
・魔法剣士の女の子。メインカラーは黄色（#f2b632）
・帽子はかぶらない。オレンジがかった赤毛の短い髪が元気にはねていて、黄色いヘアバンドをしている

・右手で、刃がうっすら光る短めの剣を高く掲げている。剣のつばに小さな宝石
・左腕に小さな丸い盾
・目だけの顔（鼻と口なし）で、勇ましく自信のある雰囲気
```

### `chara/p4.png`（緑・エルフの魔法使い）
```
4人目のキャラクターを描いてください。1人目と同じ絵柄・頭身・線の太さ・色の明るさにしてください。
・エルフの魔法使いの男の子。メインカラーは緑（#5cb85c）
・先がとがった葉っぱの形の緑のフードをかぶり、フードからとがった耳が出ている
・背中に、妖精の羽のような形にすそが分かれた緑のマント
・白っぽい金髪、緑の上着、クリーム色のズボン、こげ茶色のブーツ
・先に小さな白い花が咲いた、つるの巻きついた杖を持っている
・目だけの顔（鼻と口なし）で、おっとりとやさしい雰囲気
```

### 4人がそろったら（確認用）
```
これまでに描いた4人を、同じ大きさで横一列に並べた画像を作ってください。ほかは何も変えないでください。
```
並べた画像を縮小して、30px くらいでも見分けられるか確かめる。見分けにくいキャラは、帽子や武器を大きくしてもらう。

## ③ 表情差分（優先度 B）

元の画像を添付して、その画像を編集してもらう。ファイル名は `p1_happy.png` / `p1_sad.png` のように、p1〜p4 それぞれに作る。

### `pN_happy.png`（喜び・ゴールしたとき）
```
添付したキャラクターを元に、喜んでいるポーズにしてください。服・色・絵柄・頭身はそのままにしてください。
・目をぎゅっと閉じた「^ ^」の形の笑い目にする（鼻と口は描かないまま）
・両手を上げてバンザイし、少し飛び跳ねている
・頭のまわりに小さな星やきらきらを2〜3個だけ描く
・背景は無地の真っ白一色、縦横比は1:1
```

### `pN_sad.png`（攻撃を受けたとき）
```
添付したキャラクターを元に、攻撃を受けて困っているポーズにしてください。服・色・絵柄・頭身はそのままにしてください。
・目を「> <」の形にぎゅっとつぶる（鼻と口は描かないまま）
・目の横に小さな涙のしずく、頭の上にぐるぐるの目回しマーク
・少しよろけて、帽子（または髪）が少しずれている
・痛そう・かわいそうになりすぎず、コミカルな雰囲気にする
・背景は無地の真っ白一色、縦横比は1:1
```

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| 口や鼻が描かれる | 「口と鼻を消してください。顔は目とほっぺの赤みだけにしてください」 |
| 頭身が高くなる | 「頭の大きさを体全体の半分くらいにして、もっと短い手足にしてください」 |
| 線が黒い・細い | 「主線をこげ茶色にして、もっと太く均一にしてください」 |
| 背景に何か描かれる | 「キャラクター以外はすべて消して、背景を無地の真っ白にしてください」 |
| 4人の絵柄がそろわない | 基準の `p1.png` を添付して「この画像とまったく同じ絵柄で」と伝える |
