# 7. タイトル・UIのプロンプト

| ファイル | 内容 | サイズ | 縦横比 | 背景 | 優先度 |
|---|---|---|---|---|---|
| `ui/logo.png` | タイトルロゴ「スペル・ロード」（副題「カードで駆け引き！魔法すごろく」） | 1200×480 | 5:2（16:9 で作って上下を切る） | 透過 | B |
| `ui/dice_1.png`〜`ui/dice_6.png` | サイコロの目 6枚 | 各 256×256 | 1:1 | 透過 | B |
| `ui/card_back.png` | カードの裏面 | 240×320 | 3:4 | 画面いっぱいの絵 | C |

## ① 最初に送るプロンプト

```
これから、すごろくゲームの画面に使う、ロゴ・サイコロ・カードの裏面を描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない（ただし、ロゴで文字を指定したときだけは、その文字だけを描く）

【UIのルール】
・ゲームの画面に重ねる部品なので、形をはっきりさせ、背景は指定した色の無地一色にする
・人物は描かない

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `ui/logo.png`（タイトルロゴ）

Gemini は日本語の文字を崩して描くことがある。**A案** で文字がきれいに出なければ、**B案** で飾りだけ作り、文字はフォントで重ねる。

#### A案: 主タイトルの文字ごと作る
```
ゲームのタイトルロゴを描いてください。
・文字は「スペル・ロード」の7文字（「・」は真ん中に小さく置く中黒の点）。この文字以外の文字は描かない。字を一字一字正確に描く
・まるっこくて太い、ぽってりした手書き風の文字。文字の色はクリーム色で、こげ茶色の太いふちどり、その外側にさらに白いふちどり
・文字は横一列に並べる。「スペル」と「ロード」は同じ大きさにそろえ、ほんの少しだけ上下にはずませて、楽しい感じにする
・文字のまわりに、金色の星・きらきら・小さなサイコロ・魔法の杖を少しだけ飾る
・文字の下に、きらきら光る金色の細い道（ロード）が、ゆるくカーブして横にのびるようにする
・文字の後ろに、うすい紫色の魔法陣の円をうっすら敷く
・ロゴは横長で、画面の中央に収める（上下に余白をとる）
・背景は無地の真っ白一色
・縦横比は16:9
```

#### A案（副題つき）: 副題の文字も一緒に作る
副題は文字数が多く崩れやすい。試すなら、A案でうまくいったあとに、A案のロゴを添付して送る。
```
添付したロゴの下に、副題を小さく足してください。
・副題の文字は「カードで駆け引き！魔法すごろく」。この文字以外は描かない。字を一字一字正確に描く
・副題は、クリーム色の細長いリボンの中に、こげ茶色の文字で描く。リボンのふちはこげ茶色
・副題の大きさは、「スペル・ロード」の文字の高さの3分の1くらい
・添付したロゴの文字・色・飾りは、そのまま変えない
・背景は無地の真っ白一色、縦横比は16:9
```

#### B案: 飾りだけ作る（文字はあとでフォントで入れる）
```
ゲームのタイトルロゴの「飾りの枠」だけを描いてください。文字は描かないでください。
・横長のリボンの形の看板。リボンはクリーム色で、こげ茶色の太いふちどり
・リボンの中央は、あとで主タイトルの文字を入れるので、何も描かない無地にする
・その下に、細長い小さなリボンをもう1つ重ねる。あとで副題の文字を入れるので、こちらも何も描かない無地にする
・リボンのまわりに、金色の星・きらきら・小さなサイコロ・魔法の杖を少しだけ飾る
・リボンの後ろに、うすい紫色の魔法陣の円をうっすら敷く
・画面の中央に収める（上下に余白をとる）
・背景は無地の真っ白一色
・縦横比は16:9
```

> タイトルは「スペル・ロード ～カードで駆け引き！魔法すごろく～」（[spec.md](../spec.md) 決定事項 #15）。ロゴでは主タイトル「スペル・ロード」を大きく、副題を小さく添える。
> おすすめは、A案で主タイトルだけを作り、副題はフォントで重ねる方法。副題まで画像で作ると文字が崩れやすい。
> B案を使う場合は、主タイトルと副題の両方をフォントで入れる。

### `ui/dice_1.png`〜`ui/dice_6.png`（サイコロの目）

形をそろえるため、**`dice_1.png` を最初に作り、残りの5枚は `dice_1.png` を添付して編集** してもらう。

#### `ui/dice_1.png` — 最初に作る
```
サイコロの面を1つ描いてください。
・正面から見た、角の丸い正方形のサイコロの面（立体ではなく、面だけを真正面から）
・サイコロの色は、少し黄みがかったクリーム色。ふちに少し影をつけて、ぷっくりした感じにする
・目は「1」。中央に大きな赤い丸の目を1つ
・目は、こげ茶色のふちどりのある、くっきりした丸
・サイコロは画面の約8割の大きさで、中央に置く
・背景は無地の濃いマゼンタ（#FF00FF）一色。影は描かない
・縦横比は1:1
```

#### `ui/dice_2.png`〜`ui/dice_6.png`
下の文の「〇」と「目の並び」を書き換えて、`dice_1.png` を添付して送る。
```
添付したサイコロと、形・色・大きさ・ふち・目の大きさと色をまったく同じにして、目の数だけ変えてください。
・目は「〇」。目の色はこげ茶色（1以外は赤にしない）
・目の並び: （下の表から）
・背景は無地の濃いマゼンタ（#FF00FF）一色、縦横比は1:1
```

| ファイル | 〇 | 目の並び |
|---|---|---|
| `dice_2.png` | 2 | 左上と右下に1つずつ |
| `dice_3.png` | 3 | 左上・中央・右下に1つずつ、斜めに並ぶ |
| `dice_4.png` | 4 | 四すみに1つずつ |
| `dice_5.png` | 5 | 四すみに1つずつと、中央に1つ |
| `dice_6.png` | 6 | 左右に3つずつ、2列に並ぶ |

> 目の大きさ: 「1」の目だけ大きく赤い（日本のサイコロと同じ）。2〜6の目は「1」の目より小さくそろえる。
> 6枚そろったら並べて、目の大きさと位置が自然かを確かめる。ずれていたら、正しいものを添付して直してもらう。

### `ui/card_back.png`（カードの裏面）優先度 C
```
魔法のカードの裏面を描いてください。山札や相手の手札として表示します。
・縦長のカードの裏面を、真正面から画面いっぱいに描く（カードの外側の余白はなし）
・地の色は深い紫色。ふちに沿って、金色の細い二重の枠
・中央に、金色の丸い魔法陣の模様。魔法陣の中心に星、まわりに6つの小さな丸（6つの属性を表す: 緑・紫・赤・水色・金・黒紫）
・四すみに、小さな金色の星の飾り
・上下・左右が対称のデザインにする
・文字は入れない
・縦横比は3:4（縦長）
```

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| ロゴの文字が崩れる・違う字になる | 数回試してだめなら B案に切り替える |
| サイコロが立体（斜め）になる | 「立体のサイコロではなく、1つの面だけを真正面から描いてください」 |
| サイコロの目の数が違う | 「目の数を数えて、ちょうど〇個にしてください」 |
| カードの裏面が対称にならない | 「上下・左右を対称にしてください。中央の魔法陣を基準にそろえてください」 |
