# 4. カードのイラストのプロンプト

| 項目 | 内容 |
|---|---|
| 対象 | `card/<カードID>.png`。MVPの15種類（優先度 A）、残りの12種類（優先度 C） |
| サイズ | 480×360（縦横比 **4:3** で作って縮小） |
| 背景 | **背景つき**（透過しない） |
| 基準 | `chara/p1.png` を添付して「この絵柄に合わせて」と伝える |

## デザインの考え方

- カードの枠・名前・★はプログラムで描くので、**中央の絵だけ** を描く。
- **魔法のエフェクトが主役**。属性の色をはっきり使い、絵を見ただけで属性がわかるようにする。

| 属性 | 主な色 | 背景のおすすめ |
|---|---|---|
| 風 | 緑・若草色 | 晴れた草原の空 |
| 時 | 紫・金 | 星の出た夜空、歯車の浮かぶ空間 |
| 炎 | 赤・オレンジ | 夕焼け、火の粉の舞う空間 |
| 氷 | 水色・白 | 雪の降る景色 |
| 光 | 金・白 | やわらかい光のさす空 |
| 闇 | 黒紫・紫 | 月の出た夜（こわくしない） |

- 人物を描く場合は、**特定のプレイヤーに見えないように** 小さな後ろ姿・シルエットにとどめる（4人のうち誰が使っても違和感がないように）。攻撃される相手は、ぽんっと飛ばされる **小さなぬいぐるみのような丸いシルエット** で表す。
- 端は枠で少し隠れることがあるので、**大事なものは中央に置き、端から1割は飾り程度** にする。

## ① 最初に送るプロンプト

```
これから、すごろくゲームで使う魔法のカードの中央に入れるイラストを1枚ずつ描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【カードイラストのルール】
・魔法の効果（エフェクト）を主役にした絵。指定した「属性の色」を画面の主な色にする
・背景も描く。背景は主役より色を控えめにして、主役が目立つようにする
・大事なものは画面の中央に置き、画面の端から1割の部分には大事なものを置かない
・人物は描かないか、描く場合も小さな後ろ姿やシルエットだけにする。顔ははっきり描かない
・攻撃や妨害の魔法も、こわくならず、コミカルでかわいい雰囲気にする
・カードの枠・カード名・文字は描かない。イラストだけを画面いっぱいに描く
・縦横比は4:3（横長）

ルールがわかったら「了解」とだけ答えてください。
```

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| カードの枠や文字まで描かれる | 「カードの枠・文字を消して、イラストだけを画面いっぱいに描いてください」 |
| 属性の色が弱い | 「〇〇色をもっと画面の主な色にしてください」 |
