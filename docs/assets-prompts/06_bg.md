# 6. ボード・画面の背景のプロンプト

| ファイル | 内容 | サイズ | 縦横比 | 背景 | 優先度 |
|---|---|---|---|---|---|
| `bg/forest_tile.png` | はじまりの森のボード背景（つなぎ目なし） | 512×512 | 1:1 | 画面いっぱいの絵 | A |
| `bg/title.png` | タイトル画面の背景 | 1080×1920 | 9:16 | 画面いっぱいの絵 | B |
| `bg/forest_deco_*.png` | ボードの空きスペースの飾り | 各 256×256 程度 | 1:1 | 透過 | C |

## デザインの考え方

- **ボード背景はあくまで脇役**。上にマス・コマ・道がのるので、模様は細かく、色の明るさの差は小さくする。目立つ物（大きな木・花）は描かない。
- ボード背景は **上下左右につなげて敷きつめる** ので、つなぎ目が出ないことが一番大事。
- 飾りはボードの道の周りに置くので、真上ではなく **やや上から見下ろした角度** で描く。

---

## ① 最初に送るプロンプト

```
これから、すごろくゲームの背景と、背景に置く飾りを描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【背景のルール】
・舞台は「はじまりの森」。見習い魔法使いが最初に冒険する、明るくやさしい魔法の森
・背景の上にはゲームのマスやキャラクターがのるので、背景は主張しすぎない、落ち着いた色にする
・人物・動物・文字は描かない

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `bg/forest_tile.png`（ボード背景・つなぎ目なし）優先度 A
```
ボードの背景に敷きつめる、森の草地のテクスチャを描いてください。
・真上から見下ろした草地。やわらかい若草色の地面に、短い草の模様が全体に均一に散らばっている
・ところどころに、小さなクローバー、小さな白い花、小石、落ち葉を少しだけ。どれも小さく、まばらに、全体に均一に散らす
・大きな物、道、目立つ模様、光の当たり方のむらは入れない。画面のどこを切り取っても同じような見た目にする
・明るさと色の差は小さめにして、上にのせるマスやキャラクターが見やすいようにする
・上下左右にくり返し並べても、つなぎ目がわからない「シームレスなパターン」にする。画面の端にかかる草や花は、反対側の端につながるようにする
・縦横比は1:1
```

**つなぎ目の確かめ方と直し方**
1. 画像を縦横2枚ずつ（2×2）並べて、つなぎ目が見えないか確かめる。
2. つなぎ目が目立つときは、画像編集ソフトで「オフセット」（GIMP: レイヤー → 変形 → オフセット、Photoshop: フィルター → その他 → スクロール）で縦横半分ずらし、中央に来たつなぎ目を修復ブラシなどでなじませる。
3. または、ずらした画像を Gemini に添付して「画像の中央の十字のつなぎ目だけを、まわりになじむように自然に描き直してください。端は変えないでください」と頼む。

### `bg/title.png`（タイトル画面の背景）優先度 B
```
ゲームのタイトル画面の背景を描いてください。スマホの縦長の画面いっぱいに表示します。
・明るい魔法の森の入口から、奥へ向かってくねくねと続く小道を、少し高い位置から見た景色
・道の奥の遠くに、とんがり屋根の魔法学院の塔が見える
・木もれ日が差しこみ、空中に光の粒やふわふわ浮かぶ光の玉がただよっている
・木々はまるっこくデフォルメされていて、ところどころに大きなキノコや花
・画面の上から3分の1はタイトルロゴを重ねるので、空と木の葉だけの、すっきりした部分にする
・画面の下から3分の1はボタンを重ねるので、道と草地だけの、すっきりした部分にする
・朝のような、わくわくする温かい光
・縦横比は9:16（縦長）
```

### `bg/forest_deco_*.png`（ボードの飾り）優先度 C
1つの絵に1つの物。ファイル名の例を書いておく（数・種類は自由）。

**共通で末尾に付ける文**
```
・やや上から見下ろした角度（斜め45度くらい）で描く
・物を1つだけ、画面の中央に描く（画面の約8割の大きさ）
・背景は無地の真っ白一色。地面・影は描かない
・縦横比は1:1
```

| ファイル名（例） | プロンプト（上の「共通で末尾に付ける文」と一緒に送る） |
|---|---|
| `forest_deco_tree.png` | 「ボードの飾りに使う木を描いてください。まんまるの葉っぱのかたまりがもこもこ重なった、背の低いかわいい広葉樹」 |
| `forest_deco_pine.png` | 「ボードの飾りに使う木を描いてください。三角形を3段重ねたような、まるっこいモミの木」 |
| `forest_deco_flower.png` | 「ボードの飾りに使う花の群れを描いてください。ピンク・黄色・白の小さな花が5〜6本、葉っぱと一緒に寄り集まっている」 |
| `forest_deco_stump.png` | 「ボードの飾りに使う切り株を描いてください。年輪が見える丸い切り株で、横から小さな若葉が1本生えている」 |
| `forest_deco_rock.png` | 「ボードの飾りに使う岩を描いてください。まるっこい灰色の岩が2つ寄りそっていて、上に少し苔がついている」 |
| `forest_deco_mushroom.png` | 「ボードの飾りに使うキノコを描いてください。赤いかさに白い水玉の、大小2本のキノコ」 |
| `forest_deco_bush.png` | 「ボードの飾りに使う茂みを描いてください。まるっこい緑の茂みに、赤い木の実が少しついている」 |
| `forest_deco_crystal.png` | 「ボードの飾りに使う魔法の水晶を描いてください。地面から生えた、淡い水色に光る水晶のかたまり」（※背景はマゼンタ一色にする） |

飾りは、1つ目ができたらそれを添付して「この画像と同じ絵柄・角度・大きさで」と付け加えると、並べたときになじむ。

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| ボード背景がにぎやかすぎる | 「花や小石の数を半分にして、色の差をもっと小さくしてください」 |
| ボード背景に道や大きな木が入る | 「道や大きな物はすべて消して、草地の模様だけにしてください」 |
| タイトル背景の上下がごちゃごちゃする | 「画面の上3分の1と下3分の1を、もっとすっきりさせてください」 |
