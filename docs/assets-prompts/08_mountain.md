# 8. 2つ目のマップ「いわやまの峠道」のプロンプト

| ファイル | 内容 | サイズ | 縦横比 | 背景 | 優先度 |
|---|---|---|---|---|---|
| `bg/mountain_tile.png` | いわやまの峠道のボード背景（つなぎ目なし） | 512×512 | 1:1 | 画面いっぱいの絵 | A |
| `square/base_mountain.png` | 岩山のマスの土台（平らな石の台） | 192×192 | 1:1 | 透過 | B |
| `bg/mountain_deco_*.png` | ボードの空きスペースの飾り | 各 256×256 程度 | 1:1 | 透過 | C |

- `bg/mountain_tile.png` が無いあいだは、灰色がかった茶色の無地で表示される。
- `square/base_mountain.png` が無いあいだは、はじまりの森と同じ切り株の土台で表示される。
- 置き場所は `public/assets/` の下（例: `public/assets/bg/mountain_tile.png`）。置けば、プログラムを変えなくても使われる。

## デザインの考え方

- **ボード背景はあくまで脇役**（[6. 背景](06_bg.md) と同じ）。上にマス・コマ・白っぽい石の道がのるので、模様は細かく、明るさの差は小さくする。
- 岩山らしさは **色（灰色・砂色・赤茶）と質感（ごつごつした岩肌・小石・ひび）** で出す。大きな崖や谷は描かない（敷きつめたときに目立つため）。
- こわい・寒々しい雰囲気にはしない。日の当たった、明るく乾いた岩山にする。
- ボードは「中ほどの関所で道が2本に分かれ、左が近道（まっすぐ）、右が遠回り（くねくね）」の形。背景は敷きつめるだけなので、道の形を描く必要はない。

## ① 最初に送るプロンプト

```
これから、すごろくゲームの背景と、背景に置く飾りを描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【背景のルール】
・舞台は「いわやまの峠道」。見習い魔法使いが森を抜けた先で越える、岩肌がむき出しになった明るい山道
・日差しがよく当たる、乾いた岩山。灰色・砂色・赤茶色の岩に、ところどころ小さな高山植物が生えている
・こわい・暗い・寒々しい雰囲気にはしない。冒険の途中のわくわくする景色にする
・背景の上にはゲームのマスやキャラクターがのるので、背景は主張しすぎない、落ち着いた色にする
・人物・動物・文字は描かない

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `bg/mountain_tile.png`（ボード背景・つなぎ目なし）優先度 A
```
ボードの背景に敷きつめる、岩山の地面のテクスチャを描いてください。
・真上から見下ろした、岩肌がむき出しになった山の地面。灰色がかった砂色の岩盤に、浅いひびや岩のつなぎ目が全体に均一に走っている
・ところどころに、小石の集まり、砂利、ひび割れから生えた小さな草、黄色や紫の小さな高山の花を少しだけ。どれも小さく、まばらに、全体に均一に散らす
・大きな岩、崖、谷、道、目立つ模様、光の当たり方のむらは入れない。画面のどこを切り取っても同じような見た目にする
・明るさと色の差は小さめにして、上にのせるマスやキャラクターが見やすいようにする。全体の色は、明るい灰色がかったベージュ
・上下左右にくり返し並べても、つなぎ目がわからない「シームレスなパターン」にする。画面の端にかかる石やひびは、反対側の端につながるようにする
・縦横比は1:1
```

つなぎ目の確かめ方と直し方は、[6. 背景](06_bg.md) の「つなぎ目の確かめ方と直し方」と同じ。

### `square/base_mountain.png`（マスの土台）優先度 B
土台はアイコンの下に敷くので、**真上から見た** 形にする。はじまりの森の `square/base.png`（切り株）を添付して「この画像と同じ大きさ・角度で」と付け加えると、並べたときにそろう。
```
すごろくのマスの土台を描いてください。アイコンではなく、マスそのものの絵です。
・真上から見た、丸くて平らな石の台。上の面はなめらかに削られた明るい灰色の石で、ふちは少しごつごつしていて、ふちの一部に小さな苔と小石がついている
・中央にアイコンを重ねるので、中央は平らで模様を控えめにする
・画面いっぱいの円形にする（上下左右に少しだけ余白）
・背景は無地の真っ白一色、縦横比は1:1
```

### `bg/mountain_deco_*.png`（ボードの飾り）優先度 C
1つの絵に1つの物。ファイル名の例を書いておく（数・種類は自由）。

**共通で末尾に付ける文**
```
・やや上から見下ろした角度（斜め45度くらい）で描く
・物を1つだけ、画面の中央に描く（画面の約8割の大きさ）
・背景は無地の真っ白一色。地面・影は描かない
・縦横比は1:1
```

| ファイル名（例） | プロンプト（上の「共通で末尾に付ける文」と一緒に送る） |
|---|---|
| `mountain_deco_rock.png` | 「ボードの飾りに使う岩を描いてください。角ばった灰色の大きな岩と小さな岩が3つ寄り集まっていて、すき間から小さな草が生えている」 |
| `mountain_deco_pillar.png` | 「ボードの飾りに使う岩の柱を描いてください。赤茶色の地層のしま模様が見える、背の低いずんぐりした岩の柱」 |
| `mountain_deco_pine.png` | 「ボードの飾りに使う木を描いてください。岩のすき間から生えた、風に吹かれて少し曲がった小さな松の木」 |
| `mountain_deco_flower.png` | 「ボードの飾りに使う高山植物を描いてください。岩のくぼみに咲いた、紫と黄色の小さな花の群れ」 |
| `mountain_deco_cairn.png` | 「ボードの飾りに使う道しるべを描いてください。平たい石を5つ積み上げた、まるっこいケルン（石積み）」 |
| `mountain_deco_crystal.png` | 「ボードの飾りに使う魔法の鉱石を描いてください。岩から突き出た、淡い紫に光る水晶のかたまり」（※背景はマゼンタ一色にする） |
| `mountain_deco_bridge.png` | 「ボードの飾りに使う小さなつり橋を描いてください。木の板とロープでできた、短くて丈夫そうなつり橋」 |

飾りは、1つ目ができたらそれを添付して「この画像と同じ絵柄・角度・大きさで」と付け加えると、並べたときになじむ。
※ 飾りをボードに並べる処理は、はじまりの森の飾りと同じく、まだ作っていない。

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| 背景が暗い・こわい | 「全体をもっと明るい砂色にして、日の当たった暖かい岩山にしてください」 |
| 背景がにぎやかすぎる | 「花や小石の数を半分にして、ひびを細く・少なくしてください」 |
| 大きな岩や崖が入る | 「大きな物はすべて消して、地面の岩肌の模様だけにしてください」 |
| 写真のような岩になる | 「写実的にせず、こげ茶の主線とフラットな塗りの、絵本のような絵柄にしてください」 |
| 石の台が立体的すぎる | 「真上から見た平らな円にして、横の面は見えないようにしてください」 |
