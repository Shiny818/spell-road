# 2. マスのアイコンのプロンプト

| 項目 | 内容 |
|---|---|
| 対象 | `square/start.png`・`card.png`・`exchange.png`・`coin.png`・`gate.png`・`goal.png`（優先度 A）、`gate_broken.png`・`base.png`（優先度 B） |
| サイズ | 192×192（縦横比 1:1 で作って縮小） |
| 背景 | 透過（白一色で作って、あとで消す） |
| 基準 | 先に `chara/p1.png` を作っておき、参考画像として添付すると絵柄がそろう |

## デザインの考え方

- マスの丸い土台はプログラムで描くので、**アイコン部分だけ** を描く。
- ボード上では小さく表示されるので、**1つの物を大きく、はっきりした形** で描く。細かい飾りは少なめにする。
- アイコンどうしの大きさをそろえるため、どれも **画面の約8割の大きさ** に収める。

---

## ① 最初に送るプロンプト

```
これから、すごろくゲームのマスの上に表示するアイコンを1つずつ描いてもらいます。以下のルールを、このチャットの間ずっと守ってください。

【共通スタイル】
デフォルメされたファンタジー魔法世界のゲーム用イラスト。かわいいちびキャラの絵柄で、温かみのある絵本のような雰囲気。
・線: やや太めで太さが均一な、こげ茶色の主線（黒い線は使わない）
・塗り: フラットな塗りに、やわらかい影を1段だけ。グラデーションは控えめ
・色: 明るく温かみのある色。彩度は中くらいで、くすみすぎず派手すぎない。光は左上から当たる
・質感: 手描き風のやわらかさ。写実的な絵・3DCG風・ギラギラしたアニメ塗りにはしない
・文字・数字・ロゴ・透かし・サインは描かない

【アイコンのルール】
・ゲームのアイコン。物を1つだけ、画面の中央に大きく描く（画面の約8割の大きさ）
・とても小さく表示しても何かわかるように、形をはっきり・単純にする。細かい模様は少なめ
・主線はほかのイラストより少し太めにする
・正面か、やや上から見た角度で描く
・人物は描かない
・背景は無地の真っ白一色。地面・影・背景の飾りは描かない
・縦横比は1:1

ルールがわかったら「了解」とだけ答えてください。
```

## ② 素材ごとのプロンプト

### `square/start.png`（スタート）
```
「スタート」のマスのアイコンを描いてください。
・ふっくらした金色の星を1つ。星の中央に小さな白いハイライト
・星のまわりに、小さなきらきらを2つだけ
・これから冒険が始まる、わくわくした雰囲気
```

### `square/card.png`（カード入手）
```
「魔法のカードがもらえる」マスのアイコンを描いてください。
・少し傾いた魔法のカードを1枚。カードの裏面は濃い紫で、中央に金色の丸い魔法陣の模様
・カードのまわりから、やわらかい光がふわっとあふれている
・カードの角は丸く、カードの縁は金色
```

### `square/exchange.png`（カード交換）
```
「カードを交換する」マスのアイコンを描いてください。
・2枚の魔法のカード（片方は青っぽい裏面、片方はピンクっぽい裏面）が、少し重なって並んでいる
・2枚のまわりを、2本の丸い矢印がぐるりと回っている（交換を表す）。矢印は明るい緑色
```

### `square/coin.png`（コイン）
```
「コインがもらえる」マスのアイコンを描いてください。
・ぷっくりした金色のコインを1枚、少し斜めから見た角度で
・コインの表面に、星の形の刻印（文字や数字は入れない）
・左上に白い光の反射、コインの横にきらきらを1つ
```

### `square/gate.png`（関所・封印の扉）
```
「関所（封印された扉）」のマスのアイコンを描いてください。
・上が丸い、どっしりした石造りの小さな扉を正面から
・扉の中央に、青紫色に光る丸い魔法の封印（魔法陣の紋章）が浮かんでいる
・扉の左右に、くさりが1本ずつ斜めにかかっている
・まだひびは入っていない、しっかり閉じた状態
・こわくならないように、まるっこい形にする
```

### `square/gate_broken.png`（関所・封印が砕けた状態）優先度 B
`gate.png` を添付して編集してもらう。
```
添付した扉のアイコンを元に、封印が砕けた状態にしてください。扉の形・色・絵柄はそのままにしてください。
・中央の魔法の封印が、ガラスのように割れて、かけらが外側に飛び散っている
・くさりは切れて垂れ下がっている
・扉は少し開いていて、すき間から温かい金色の光がもれている
・通れるようになった、うれしい雰囲気にする
・背景は無地の真っ白一色、縦横比は1:1
```

### `square/goal.png`（ゴール）
```
「ゴール」のマスのアイコンを描いてください。
・ポールに立てた旗を1本。旗は赤と白の市松模様で、風になびいている
・ポールの先に金色の丸い玉
・旗のまわりに小さな紙吹雪を3〜4個
```

### `square/base.png`（マスの土台）優先度 B
土台はアイコンの下に敷くので、**真上から見た** 形にする。
```
すごろくのマスの土台を描いてください。アイコンではなく、マスそのものの絵です。
・真上から見た、丸い平らな切り株。年輪が見えて、ふちに少し苔
・中央にアイコンを重ねるので、中央は平らで模様を控えめにする
・画面いっぱいの円形にする（上下左右に少しだけ余白）
・背景は無地の真っ白一色、縦横比は1:1
```

## うまくいかないとき

| 困りごと | 追加で伝えること |
|---|---|
| 細かすぎる | 「形をもっと単純にして、細かい模様を減らしてください。小さく表示するアイコンです」 |
| 大きさがばらばら | 前に作ったアイコンを添付して「この画像と同じくらいの大きさ・余白で」 |
| 旗やコインに文字が入る | 「文字・数字・記号はすべて消してください」 |
